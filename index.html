📊 Google Sheets 💡 Como publicar a planilha?
Como conectar o Google Sheets
PASSO 1 — Abrir a planilha no Google Sheets
Certifique-se que a planilha tem as mesmas colunas do CSV original (separador ;).
PASSO 2 — Publicar na web
No menu: Arquivo → Compartilhar → Publicar na Web
Selecione a aba correta e o formato Valores separados por vírgula (.csv). Clique em Publicar.
PASSO 3 — Copiar o link gerado
O Google vai gerar um link no formato:
https://docs.google.com/spreadsheets/d/e/…/pub?output=csv
PASSO 4 — Colar no dashboard
Cole o link no campo acima e clique em Carregar dados. A partir daí, o dashboard atualiza sozinho a cada abertura.
⚠️ IMPORTANTE: A planilha precisa estar com acesso "Qualquer pessoa com o link pode ver" para o dashboard conseguir ler os dados.
